# Generated outputs (not published in this repository)

Generated result files, derived CSV/XLSX tables, figures and model predictions are intentionally excluded from the public repository. The `outputs/` directory is Git-ignored except for this README.

Each analysis script writes to `outputs/<script_folder>/` as described in the main README. The article's numeric results are **not** archived here. Users must obtain the publicly available source data and rerun the analysis scripts to generate outputs. The repository does not contain standalone plotting scripts for Figures 2, 3, 5, 6 or 7.

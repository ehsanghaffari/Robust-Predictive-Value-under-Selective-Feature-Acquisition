# Generated outputs (not tracked)

Each analysis script writes to `outputs/<script_folder>/` as described in the main README. This folder is Git-ignored except for this README. Result files, tables, figures and model predictions are regenerated from the public source data by running the scripts; the case-level split identifiers are released in `results/split_ids/`, and the article reports its results in the main text and Online Resource 1. The repository does not contain plotting scripts for Figures 2, 3, 5, 6 or 7; their data are written to the CSV outputs listed in the main README.

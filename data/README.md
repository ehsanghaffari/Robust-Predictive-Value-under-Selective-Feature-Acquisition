# Input data

- `crss_zips/`: NHTSA archives `CRSS2016CSV.zip` through `CRSS2024CSV.zip` (downloaded automatically by the main identification and ML scripts if absent).
- `penndot/Statewide_<year>/<TABLE>_<year>.csv`: PennDOT files for optional supplementary audits.

Input data are not committed to Git.

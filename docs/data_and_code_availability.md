# Data and Code Availability

**Data availability.** The study uses publicly available 2016–2024 Crash Report Sampling System (CRSS) data from the [National Highway Traffic Safety Administration](https://www.nhtsa.gov/crash-data-systems/crash-report-sampling-system). Data for supplementary Pennsylvania crash audits were obtained through the [PennDOT Crash Information Tool](https://crashinfo.penndot.pa.gov/). Original data are available from their respective providers.

**Code availability.** Analysis code is available at https://github.com/ehsanghaffari/Robust-Predictive-Value-under-Selective-Feature-Acquisition under the MIT License. The repository contains scripts for data preparation, identification, sensitivity analysis, and machine-learning evaluation.

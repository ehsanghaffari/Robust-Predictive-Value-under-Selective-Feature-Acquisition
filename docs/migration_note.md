# Repository transition

In November 2026, the default branch was updated to the CRSS-centered workflow supporting *Robust Predictive Value under Selective Feature Acquisition: Exact Identification Boundaries in Crash Alcohol Testing*.

The earlier root-level PennDOT scripts (`01_PennDOT_Data_Preparation.py`, `02_PennDOT_RFV_Identification.py`, and `03_PennDOT_ML_Premise.py`) are retained in Git history, including commit `93244ac892ba9cbcdbb1323518dd9fba5ebde37c`. They are not equivalent to the CRSS analysis scripts and should not be used to reproduce the CRSS results.

The public repository includes analytical scripts and documentation but does not host the original datasets, generated result files, or standalone plotting scripts for Figures 2, 3, 5, 6, or 7.
